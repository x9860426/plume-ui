# UI Engine (暂定名)

一个专注于 UI 的引擎项目。项目名称尚未最终确定，当前仓库名 `ui-engine` 为工作代号。

## 目标

- 提供可复用的 UI 引擎与组件能力
- 支持在商业产品中使用
- 允许使用者保留自己的业务代码与修改不公开
- 禁止将本 UI 引擎本身作为独立商品出售

## 授权说明 (重要)

本项目拟采用自定义 Source-Available 许可证，不是 OSI 定义下的严格开源许可证。

允许:

- 在个人或商业项目中使用
- 修改源码并用于自己的产品
- 将修改后的代码保留为私有
- 随产品分发编译后的产物

禁止:

- 单独出售、出租、转售本 UI 引擎
- 将本 UI 引擎或其实质性衍生版本包装成独立 UI 引擎/SDK/模板进行商业售卖
- 使用项目名称或作者名义进行误导性宣传

完整条款以 [LICENSE](LICENSE) 为准。当前许可证为草案，正式发布前建议请专业律师审阅。
