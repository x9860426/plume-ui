# 下拉按钮收编为系统派发 — 迁移指南

> 日期：2026-10-23
> 目的：把下拉按钮从"各处内联自己画"收编进 `DropdownSystem` 系统派发，全引擎下拉唯一实现。
> 根因：AI 新建悬浮窗时下拉按钮自己绘制，自适应翻转/裁剪滚动/吞点击防穿透等逻辑各写一遍全是 bug。
> 标准来源：主题工作室悬浮窗 tab3 的 6 行下拉（完整闭环、好看），抽取为系统唯一实现。

---

## 一、核心思想

**收编前**：每个窗口/页面各自内联画下拉按钮 + 自管展开状态 + 自写裁剪滚动 + 自画滚动条。
**收编后**：业务只声明"这里有个下拉、选项是这些、当前选第几个、改选写哪个变量"，系统全包。

```
业务声明意图（draw） → 系统画按钮 + 管展开/收起 + 画列表浮层 + 滚动 + hover + 写值
```

## 二、新建文件（2 个）

### `src/ui/win/DropdownSystem.h`

系统派发接口。核心三段式：

```cpp
struct DropdownRequest {
    Rect btnRect;                          // 按钮矩形（屏幕绝对坐标）
    const char* const* items = nullptr;    // 选项文本数组
    int itemCount = 0;                     // 选项数
    int selected = 0;                      // 当前选中索引（读取展示）
    int* target = nullptr;                 // 改选写值目标（null = 业务自理）
    bool* dirty = nullptr;                 // 值变化时置 true（可选，配合重启/重配）
    const char* id = "";                   // 逻辑名（窗口内唯一，跨帧续期展开/滚动）
    float itemH = 0;                       // 列表项高（0 = 默认 20×scale）
    Font* font = nullptr;                  // 文字字体（nullptr = g_uiCtx.smallFont）
    float upBound = 0, downBound = 0;      // 弹出约束区屏幕 y（0 = 不约束）
};

class DropdownSystem {
    bool draw(dev, win, req, alpha);           // render：声明+画按钮，返回 open 态
    void renderPopups(dev, win, alpha);        // render 末：画所有展开浮层
    DropdownHit handlePress(win, m);           // click：返回是否消费+命中信息
    void updateHover(win, m);                  // hover
    bool handleWheel(win, m, delta);           // wheel
    void endFrame();                           // 帧末失活
    void removeWindow(winId);                  // 窗口删除清理
};
```

### `src/ui/win/DropdownSystem.cpp`

实现内容 = 主题工作室原 tab3 六行下拉的完整闭环搬入：
- 按钮三态（普通 `inputBorder@180` / hover 或开 `accent@180` / 底 `bg2@160`）
- 矢量小三角箭头（`fillTriangle`，SDF 软边）
- 弹出位置自适应翻转（向下不足向上翻，两侧都不足取更大侧压缩）
- 列表底 `tabBg@250` + 边框 `inputBorder@200`，圆角 4×scale
- 项 hover 高亮 `accent@60`，选中文字 `accent`，未选中 `text@200`
- 裁剪滚动（`pushScissorRect` 内缩 2px 避圆角）
- 迷你滚动条（3px 宽，轨道 `inputBorder@100`，拇指 `accent@170`）
- 打开即定位选中项到可见区中部
- 吞点击防穿透（点选项/点外部/切页均关闭）
- 单开（同窗口同时只开一个下拉）
- 帧末失活（未续期 → active=false, open=false）
- 改选写值：`target` 非 null 时 `*target = newIndex`；`dirty` 非 null 且值变化时 `*dirty = true`

> 完整代码见仓库 `src/ui/win/DropdownSystem.h` 和 `.cpp`。

## 四、业务怎么用（AI 新建悬浮窗范例）

### 最简下拉（选项写全局变量）

```cpp
// render 里：
static const char* opts[] = { "选项A", "选项B", "选项C" };
g_dropdowns.draw(dev, win, { btnRect, opts, 3, g_uiCtx.someValue, &g_uiCtx.someValue, nullptr, "my_dd" }, alpha);

// render 末尾（所有内容画完后）：
g_dropdowns.renderPopups(dev, win, alpha);

// click 开头：
if (g_dropdowns.handlePress(win, m).consumed) return true;
// hover 里：
g_dropdowns.updateHover(win, m);
// wheel 里：
if (g_dropdowns.handleWheel(win, m, delta)) return true;
```

### 需要切后重启的下拉（带 dirty）

```cpp
g_dropdowns.draw(dev, win, { btnRect, opts, count, g_uiCtx.renderRes,
    &g_uiCtx.renderRes, &g_uiCtx.renderResDirty, "render_res_dd" }, alpha);
```

### 选项写页面私有状态

```cpp
State& s = win.getState<State>();
g_dropdowns.draw(dev, win, { btnRect, opts, count, s.selIdx, &s.selIdx, nullptr, "page_dd" }, alpha);
```

### 弹出位置约束（列表不出内容区）

```cpp
// upBound/downBound = 内容区顶/底屏幕 y，系统自适应翻转
g_dropdowns.draw(dev, win, { btnRect, opts, count, sel, &sel, nullptr, "dd", 0, font, contentTop, contentBottom }, alpha);
```

## 五、禁止事项（扩展代码不得自写）

| 禁止 | 该怎么做 |
|------|----------|
| 自画下拉按钮（drawRoundedRect + 边框 + 箭头） | `g_dropdowns.draw` |
| 自管 open/展开状态（bool ddOpen） | 系统按 id 跨帧续期 |
| 自写裁剪滚动（pushScissorRect + scrollY） | 系统自动裁剪滚动 |
| 自画滚动条 | 系统自动迷你滚动条 |
| 自判弹出位置（if 向下空间不足...） | 传 upBound/downBound，系统自适应 |
| 自写吞点击防穿透 | `handlePress` 返回 consumed |
| 自写打开定位选中项 | 系统自动定位到可见区中部 |
| 第二套下拉实现（pctl 或别处） | 全引擎下拉唯一走 DropdownSystem |
