## 修复清单

### 1. 图片系统上游（新增）
- 新增 `src/ui/win/ImageSystem.{h,cpp}`，已登记进 `CMakeLists.txt` 源清单。
- 能力：内存解码（中文路径）→ 面积平均重采样（预乘 alpha）→ `createTexture` → 贴图四角（vColor 乘算）。
- **缓存键 = 设备指针 + 路径 + 量化尺寸**（尺寸量化到 16 的倍数）。设备重建后旧键自然失效。
- `AppWindow::initDevice()` 首行调用 `g_images.releaseAll()`：设备重建即清缓存，双保险。

### 2. DropdownSystem
- **重复 id 系统兜底**：同一窗口同一帧重复声明同一 `id` 时自动派生 `name#2`、`name#3`…
  （根因：状态按 `(winId, id)` 存，后声明复用同一状态并覆盖前者 `btnRect` → 点第一个下拉没反应）
- **字号单源**：新增 `ui::dropTextPx(ctrlH) = ctrlH × 0.46`（下限 8）；按钮文字与列表项文字统一走 `drawTextScaled`，
  不再用 `drawTextLeftAt`（字号 = 图集原生大小，与控件尺寸脱钩）。

### 3. 单位契约
- `UiContext.h` 顶部新增「单位契约」注释块（scale / winW·H / 窗口实例 / 配置表 / 区域请求 / pageScale）。
- 新增 `UiContext::pageScale(h) = max(h/600, 0.5) × uiScaleUser` 单源；`MainUI::computeLayout` 改用它。
- `RegionSystem.h` 的 `RegionRequest` 注释改为「屏幕绝对坐标，系统不做 scale 换算」——与实现一致。
- `WindowInstance.x/y/w/h` 注明「屏幕像素，不是配置表逻辑像素」。

### 4. 右上角安全区
- 新增 `wbtn::rightButtonsWidth(win)`：右边距 + 各按钮宽 + 间距，按窗口实际启用的按钮累加。
- 扩展内容右边界唯一来源：`win.x + win.w - rightButtonsWidth(win)`，避免被关闭键压住。

### 5. 处理器注册文档
- `HandlerRegistry.h` 注明：滑条/色板/可拖拽分割线必须同时注册 `drag` + `release`，
  否则「点一下能改值、按住拖动没反应」；缺 `release` 会导致拖拽标志无法复位。

### 6. 字体图集满保护
- `Font` 新增 `failedCps_`（放不下的码点）与 `atlasFull_`（4096² 仍失败）。
- 图集满时：本批新码点从 `bakedCps_` 撤销并记入失败集，日志只告警一次；
  `atlasFull_` 置位后新字形直接丢弃，不再每帧走全量 4096² pack（原症状：每帧数百 ms 递增尖峰）。
- `init` / `rebake` 复位这两个标记（换密度后容量需求变化，允许重新尝试扩容）。

### 7. 观感对齐
- `UiContext.scrollbarStyle` 默认 `0`（细轨）→ `2`（胶囊·无按钮），全引擎滚动条统一。
- 关闭键无需改：`WindowButtons.cpp` 本来就是矢量叉，不是字体字符。

## 补充：下拉字号错位修复（2026-11-05 晚）

- **根因**：`DropdownRequest` 在 `font`/`upBound` 之间插入 `fontSize`，而调用方普遍用 11 参数
  按位置聚合初始化 → 后续字段整体错位，`upBound`（窗口 y）被当字号 → 文字巨大且随窗口移动变化。
- **修复**：
  1. `fontSize` 移到 `DropdownRequest` / `DropdownState` 末尾，头文件写明「新增字段只能追加」。
  2. 字号收编 `wctl::textPxForCtrl(ctrlScreenH)`（屏幕像素 ÷scale ×0.46，下限 11，返回逻辑像素），
     下拉按钮 / 列表项 / `drawComboBtnStyled` 共用；删除各自的内联公式。
  3. `drawComboBtnStyled` 由 `drawTextLeftAt`（图集原尺寸）改为 `drawTextScaled` + 字号单源。
  4. `fontSize` 增加 6..72 区间防御，误传时回落自动并告警一次。
- **验证**：`0-Verify` 编译零错误零警告；`--shot` 冒烟正常（概览页「海洋蓝」下拉字号随控件高度）。
- 游戏侧同日修复并补齐，细节见游戏项目 `记忆-2026-11-05-下拉字号错位修复.md`。
