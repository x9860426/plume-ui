# 分割器系统派发 — 移植手册

> **功能**：Splitter（分割器/分隔面板）收编为系统派发 `g_splitters`，统一收编分割条的绘制与拖拽（三态视觉、拖拽写值、范围 clamp、吞点击防穿透、帧末失活）。
>
> **适用**：已具备 `RegionSystem` + `DropdownSystem` 系统派发架构的引擎分支（988- / 988-19 等）。
>
> **改动规模**：新建 4 文件 + 改 12 文件。全部为追加式改动（不删既有代码），零破坏性。
>
> **已验证**：988-19（Release 28/28 + Debug 58/58 零错误零警告）、988-（Release 26/26 零错误零警告）。

### SplitterSystem.h 接口契约（核心，业务接入只看这个）

```cpp
struct SplitterRequest {
    Rect barRect;              // 分割条热区（屏幕绝对；建议厚度 10×scale 好命中）
    bool vertical = true;      // true=垂直条（分左右，拖动改 x）；false=水平条（分上下，改 y）
    float minPos = 0;          // 分割位置下限（屏幕坐标）
    float maxPos = 0;          // 分割位置上限（必须 > minPos）
    float* target = nullptr;   // 分割位置写值目标（屏幕坐标；null = 业务自理）
    bool* dirty = nullptr;     // 位置变化时置 true（可选）
    const char* id = "";       // 逻辑名（窗口内唯一，跨帧续期）
};

struct SplitterHit { bool consumed = false; const char* id = nullptr; };

class SplitterSystem {
public:
    bool draw(RenderDevice* dev, WindowInstance& win, const SplitterRequest& req, float alpha);
    SplitterHit handlePress(WindowInstance& win, const Vec2& m);
    void handleDrag(WindowInstance& win, const Vec2& m);
    void endDrag();
    void updateHover(WindowInstance& win, const Vec2& m);
    void endFrame();
    void removeWindow(int winId);
};
```

### 业务接入三件事（声明式，零拖拽代码）

```cpp
// render：声明分割 + 画条（最后画，覆盖面板之上）
g_splitters.draw(dev, win, { barRect, vertical, minPos, maxPos, &pos, nullptr, "id" }, alpha);
// click 开头：吞点击防穿透
if (g_splitters.handlePress(win, m).consumed) return true;
// drag / release / hover：系统写值
g_splitters.handleDrag(win, m);   // drag
g_splitters.endDrag();            // release
g_splitters.updateHover(win, m);  // hover
```

## 四、设计要点（供理解，非移植必需）

- **声明式写值**：`target` 非 null 时拖动中系统直接 `*target = newPos`，业务 render 按该值布局两侧面板（几何单源在业务 layout）。与 DropdownSystem 的 `target`/`dirty` 同款。
- **嵌套分割**：多个 splitter 各自独立 `id`，按 `winId+id` 独立续期，可任意组合（左|右 再上|下嵌套等）。
- **帧末失活**：`endFrame` 把未续期的条 `active=false, dragging=false, hover=false`（切页/窗口隐藏/tab 切换自动收起拖拽态，防残留）。
- **窗口删除清理**：`removeWindow` 在 `LayerStack::flushDisposed` 调用，窗口物理删除时清其全部分割条状态。
- **快照迁移**：`AppSnapshot` 加 `splitters` 字段，`applySnapshot`/`takeSnapshot` 各 `std::move` 一行，F2 切后端/重启时拖拽态整体迁移。
- **滚动补偿**（页面侧）：水平条分割位置是屏幕绝对 y，页面滚动（dy 变化）时逐帧 `hPos += dy - lastDy` 补偿；垂直条 x 不受滚动影响，零补偿。详见 `Pages_Splitter.cpp` render。
- **视觉**：热区居中胶囊条（4×scale 厚，圆角=厚度/2）+ 三态边框（普通 inputBorder@140 / hover accent@180 / 拖拽中 accent@220）。
- **绘制风格**（`g_uiCtx.splitterStyle`，参考滑动条 `sliderStyle` 模式，主题工作室「其他UI」标签下拉切换）：
  - `0`=默认胶囊（bg2 底 + 三态边框）
  - `1`=细线（1.5×scale 细线，三态色）
  - `2`=双线（两条平行细线，间距 4×scale）
